PULSO 3D

Como ler esta visualização

Pulso 3D é uma visualização experimental da mesma infraestrutura científica do Pulso Hídrico MS. Não substitui o modo 2D.

Codificação visual

  • Largura dos rios representa descarga modelada GloFAS v4. O relevo 3D representa a topografia real, com exagero vertical apenas para leitura visual.
  • Cor representa climatologia mensal da temperatura da água DynQual 1980–2019.
  • A largura fluvial utiliza uma transformação logarítmica fixa para manter comparabilidade entre meses. Os rios são projetados sobre o DEM.

Escala temporal

Este protótipo usa 12 estados mensais de 2025. O dia de referência de cada mês é o dia disponível mais próximo do dia 15.

Gestos

Arraste para mover. Use pinça para zoom. Em dispositivos compatíveis, dois dedos também permitem inclinar e rodar a vista. Use ⌂ para retornar a Mato Grosso do Sul inteiro.

Limitações

A descarga é modelada, a temperatura é climatológica e a transferência dos valores GloFAS para a geometria PIN MS é uma operação cartográfica de visualização. O terreno usa Terrain Tiles (Mapzen/AWS Open Data), com exagero vertical e sem alterar os valores hidrológicos.
